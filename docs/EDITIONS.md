# 改稿版と旧版

本文の章構成を変更する改稿では、読書中の位置を新しい章へ読み替えない。

- 現在の本棚は `content/books/` を掲載する。
- 保存した初版は `content/editions/` に置く。元の章本文と `book.json` を保存し、通常の生成処理で旧版を再生成する。非公開の講評・プロットは入れない。
- 初版の `/books/<id>/read/01.html` 形式のURLと、既存の読書位置の保存キーを維持する。
- 改稿版には `edition`（例：`revised-20260918`）を設定する。本文URLは `/books/<id>/read/<edition>/01.html`、読書位置も版ごとに分ける。
- 初版の作品紹介と全文は `/books/<id>/editions/original/` に置く。紹介ページと読書ページで版を表示し、別の版へ移るリンクを置く。
- 本棚の冊数と検索結果は現在版だけを数える。読書位置のカタログには旧版も含め、旧版を読んでいた人はその続きを開ける。

2026-09-18：『雨を閉じこめる』を序・本編十八章へ改稿。初版三十章・80,684字を保存。人物画・配置図は維持し、挿入先を改稿の場面へ合わせた。旧版の本文は変更していない。

今の保存先は一作品につき初版一つに対応する。さらに複数の大改稿を保存する場合は、版の識別子をキーにした保存先へ拡張すること。既存の改稿版URLを別の章構成で上書きしない。

2026-09-18：第二〜四作も別版へ移行。四作すべての旧本文100編を保存し、改稿版89編とはURL・しおりを分離。`docs/archived-manuscripts.json` は改行コードだけをLFへそろえた旧本文のSHA-256。旧版の意図しない本文変更をテストで検知する。
