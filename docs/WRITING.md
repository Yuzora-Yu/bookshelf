# 執筆・人物造形の方針

ユーザーの制作上の希望を、次作以降にも引き継ぐための記録。各作品の具体的な仕掛けや犯人は記載しない。

- 人物の発言は作者の正解と同一ではない。嘘、見落とし、思い違い、保身、言い損ねを、その人物の事情に応じて描いてよい。全員に機械的に秘密を割り当てる必要はない。
- 心理的な成長や後退を描いてよい。序盤の設定を守るために、経験後も同じ態度を続けさせない。変化には出来事と迷う時間を与える。
- 主人公の得意技は、身についた背景、日常での使い道、失敗、限界まで描く。第三作では空間把握と荷造りの経験を扱った。終盤だけ万能にしない。
- 善良さを、無条件に人を信じることや、際限なく引き受けることと同一にしない。助け方を学ぶことも人物の成長になり得る。
- 被害者、犯人、脇役にも、事件以前の生活や他者との関係を持たせる。口調や小物だけで個性を説明しない。
- 読者が知り得ない情報を解決の直前に足さない。人物が嘘をつくことと、作者が必要な観察を隠すことは区別する。
- 冒頭には続きを読みたくなる具体的な出来事を置く。再読や終盤で意味が変わる仕掛けは、最初の記述そのものを虚偽にしない形で設計する。
- 紹介文は所属・関係・序盤の行動を自然に伝える。気取った対比や「性格＋象徴的小物」の定型を避け、ネタバレを含めない。
- 挿絵の注釈と図中の文章は、場所・人物の名前、図の読み方に必要な短い案内にとどめる。「本文で定めていない」「省略した」「描いていない」など制作上の説明・検証記録は読者に出さない。説明不足や図の不整合は、長い断り書きで補わず図そのものを直す。
- 他作品の調査から学ぶのは構成・考え方。固有の事件、人物、台詞、図像は持ち込まない。調査資料の範囲と、自分の推論を分けて記録する。
- 人物画は鉛筆を基調とする。第三作の漫画寄りの方向では、体格・年齢・顔立ちの差をつけ、全員を整った美男美女にしない。過度な精密さより、作品を読む余地を残す。

本文、プロット、時系列、図を往復して点検する。制作過程のネタバレ資料は公開リポジトリに入れない。
