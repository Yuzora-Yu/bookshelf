# 設計判断

- Node.jsの標準機能のみで静的HTMLを生成する。更新頻度・規模に対してサーバーやCMSの運用は不要。HTMLはJSが無効でも読める。
- 原稿と作品情報をページ実装から分離する。作品数・ジャンル・章数はデータから生成する。
- `/bookshelf/` を既定の配置先にする。ルート・別階層でも同じ生成器を使える。
- yu-zora.comの紺色と淡い橙を引き継ぎ、読書部分は生成りの紙と明朝体にする。外部フォントを使わず端末の日本語フォントを使う。
- 原稿は完成済み『雨を閉じこめる』の30章をコピーした。制作資料は公開対象に含めない。人物画はユーザーが採用した中間段階の線画を採用し、誇張した別案は使わない。
- 各章は固定HTML。検索・読書設定・しおりのみクライアント側JavaScript。読書位置は作品IDごとに保存し、破損値や範囲外の章番号を無視する。
- 人物画・配置図は読書を遮らない開閉式。北町資料室の図は該当章にのみ掲載する。
- Pages公開は手動実行。ポータル本体のデプロイ方式を決めつけない。公開先設定をビルド時に注入し、成果物を移植できるようにする。
- 試験では文字数だけでなく、生成した全HTMLのリンク・画像・フラグメントも解決する。公開前の視覚確認は別途行う。

## 旧版のアクセス制御（2026-09-20）

旧版の閲覧制限はCloudflare Workerで、ASSETS呼出しより前に行う。最新版の経路と共用図版は認証不要とし、ビルド時に生成する版ポリシーから判定する。URLのデコードと曖昧な経路の拒否を先に行い、画面、直接URL、全文テキスト、旧版専用画像に同じ判定を適用する。

セッションにはサーバー側Secretで署名した8時間のCookieを使用する。POSTは同一オリジンに限定し、認証画面はsame-originのReferrer-Policyを使ってフォームのOriginを維持する。認証済み応答を共有キャッシュへ保存しない。Secret不足時は旧版だけを閉じる。純静的ホスティングでは認証を担保できないためPagesへの公開ワークフローを廃止した。Git管理の原稿や履歴を暗号化する仕組みではなく、本棚サイトの閲覧制御である。

Wranglerは4.135.0を開発依存として固定。従来の4.120.0では本番のcompatibility_dateに対応するローカルランタイムが起動しなかったため更新した。依存監査で検出事項は0件。


## 共通ポリシーと公開URL（2026-10-04）

本棚・作品紹介・読書ページから、ポータルの運営者情報、プライバシー、利用規約、免責事項、問い合わせへ直接移動できる。読書ページでは本文と章移動の後に配置する。本文、版別URL、読書位置、旧版の認証は変更しない。

公開オリジンの既定値は `site.config.json` の `siteUrl`。`SITE_URL` があれば優先し、通常のビルドでも本番設定からcanonicalとサイトマップを生成できる。


## サイト間のナビゲーション（2026-10-04）

本棚・作品紹介・読書ページの上部に、YU-ZORAロゴとGAMES、BOOKS、TOOLS、PROJECT SIXTH、ABOUTへの共通ナビを配置する。ロゴはポータルのトップへリンクする。共通ヘッダーは最大幅1180px、通常68px、スマートフォン108pxの高さとし、ポータルと同じ紺色・書体・余白を使う。本棚・作品紹介には作品一覧・本棚についての小さな補助ナビを置く。

読書ページでは共通ナビをスクロールに追従させず、目次・表示設定の固定ヘッダーを維持する。紙色、本文の明朝体、読書設定、版別のアクセス制御は読書用のレイアウトが管理する。

## 限定閲覧作品の暗号化配信（2026-10-17）

限定閲覧の現行作品は、通常の公開原稿コレクションへ入れない。リポジトリ外で同じ静的生成器から紹介・読書ページ・全文・図版・作品別カタログを生成し、`scripts/seal-private.mjs` で各ファイルをAES-256-GCM暗号化する。Gitと公開ビルドには暗号文と経路・型・サイズのマニフェストだけを置く。

復号鍵はパスワードから導出せず、32バイトの乱数を `PRIVATE_BOOK_KEY` としてWorkerのSecretへ保存する。`PRIVATE_BOOK_PASSWORD` は閲覧認証用。本文・鍵・パスワードを静的HTMLやブラウザJavaScriptへ埋め込まない。公開ビルドは秘密値を必要としない。

Workerは対象作品の全経路を通常の版別認証より先に処理し、署名付きCookieを確認してからASSETSの暗号文を取得・復号する。章・紹介・全文・カタログ・図版が同じ認証対象。暗号文の直接URLは404。取得した経路をGCMの追加認証データとして使い、別経路の暗号文への差替えも拒む。

限定閲覧の応答は `private, no-store, no-transform` と検索除外ヘッダーを付ける。復号後のHTMLへ配信層が計測タグ等を付加する変換も抑止する。条件付き取得とRangeによる認証迂回を許さない。Cookieは8時間、HttpOnly / Secure / SameSite=Lax。ログインは同一オリジンのPOSTのみとし、秘密値・復号・設定の不備は閉じて返す。ログインPOSTには、IPを直接保存しない署名由来の識別子で5回/60秒の制限を掛ける。制限は認証試行だけに適用し、読書には適用しない。

限定作品を公開本棚・共通カタログ・サイトマップへ自動で追加しない。紹介ページの読書位置取得には認証対象の作品別カタログを使う。公開へ切り替える場合は、本文の掲載範囲と配信経路を別途変更する。
