# 作品の追加・更新

1. `content/books/` に半角英小文字・数字・ハイフンの作品IDでフォルダーを作ります。公開後はURLとしおりを維持するためIDを変えないでください。
2. `book.json` を下記形式で作ります。
3. `chapters/01_章題.md`、`02_章題.md`…と連番で原稿を置きます。各ファイルの1行目を `# 第一章　章題` にし、空行の後に本文を書きます。
4. `public/assets/books/<作品ID>/` に表紙や任意の挿絵を置きます。
5. `npm run check`、`npm run build`、`npm test` の後、PCとスマホ幅でページを確認します。

```json
{
  "id": "new-story",
  "title": "新しい物語",
  "reading": "あたらしいものがたり",
  "subtitle": "作品の副題",
  "number": "02",
  "genres": ["ファンタジー"],
  "tags": ["旅", "短編"],
  "status": "ongoing",
  "publishedAt": "2026-10-01",
  "updatedAt": "2026-10-01",
  "featured": false,
  "description": "本棚と作品紹介に表示する、ネタバレのない紹介文。",
  "intro": ["あらすじの一段落目。", "二段落目。"],
  "cover": "cover.svg",
  "characters": [],
  "illustrations": []
}
```

`status` は `completed`（完結）または `ongoing`（連載中）。本棚は掲載日の新しい順です。`featured: true` の作品が先頭の特集になります。一度に1作品だけに設定してください。なければ最新作を表示します。新しいジャンルも自動で検索欄に追加されます。

任意項目：`portrait`（人物画ファイル名）、`portraitCaption`、`characters`（`name`・`reading`・`description` の配列）、`illustrations`（`chapter`・`file`・`alt`・`caption` の配列）。画像名にパスは含めません。表紙は縦横比480:680を推奨します。既存作品の表紙SVGを構図の参考にできます。

本文の記法は限定しています。空行で段落、段落内改行はそのまま改行、`**強調**`、行頭の `> ` で引用、単独の `＊` で場面転換。HTMLや任意のMarkdownリンクは解釈しません。本文の安全な表示と読書の一貫性を優先しています。

公開後に章を増やすときは末尾に追加してください。章番号と段落番号がしおりの基準です。既存章の途中に章や段落を挿入すると、保存済みしおりの位置がずれることがあります。大きな改稿時は別作品IDにするか、しおりの移行を別途設計してください。

制作メモ・犯人表・プロット・検証資料は `public/` に置かないでください。`public/` の内容はすべて公開されます。配置図は表示時期を章番号で指定できますが、アクセス制限ではありません。
